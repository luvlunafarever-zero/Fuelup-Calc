# Fuelup Calc

> 燃油加注计算器 — 专为手机屏幕设计的轻量级 Web 工具

一个纯前端单页应用，用于快速计算加油时应加多少升油、对应的费用金额，以及加油站优惠折扣后的实际支付金额。UI 设计参考 Vuetify Material Design 风格，针对手机屏幕优化，支持键盘弹起时自动调整布局。

## 快速开始

使用 **Chrome** 或 **Firefox** 浏览器直接打开 `Dev/fuelup_calc.dev.html` 即可使用，无需构建工具或服务器。

> **iOS 用户请注意**：iOS 平台所有浏览器（包括 Chrome、Firefox）均基于 Safari 的 WebKit 内核，对 `file://` 协议下的 `localStorage` 支持不完善，直接打开本地 HTML 文件将无法持久化数据。建议在 Android 设备上使用，或将 HTML 部署到服务器后通过 HTTP 访问。

## 功能概览

| 功能 | 说明 |
|------|------|
| 加油量计算 | 根据油箱容积、隐藏油量、剩余续航、平均油耗自动计算可加注升数 |
| 费用估算 | 结合汽油单价，实时计算预计花费及每公里花费（含折扣对比） |
| 自动保存 | 所有输入数据自动保存至浏览器 localStorage，关闭页面不丢失 |
| 移动端键盘适配 | 键盘弹起时固定标题栏自动位移，避免遮挡输入区域 |
| 一键重置 | 带二次确认（Bottom Sheet）的 Reset 功能，防止误操作 |
| 可折叠配置面板 | 油箱参数、折扣参数等低频设置项默认折叠，常用输入项始终可见 |
| 逐项清空 | 每个输入框自带清空按钮，悬停/聚焦时显示 |
| 折扣计算 | 输入每升优惠价和加油机金额，自动计算实际支付金额和加油容积，折扣百分比实时反映在标题栏 |

## 输入参数

| 参数 | 位置 | 说明 | 默认值 |
|------|------|------|--------|
| 油箱总容积 (L) | 配置面板 | 车辆油箱的最大容量 | — |
| 隐藏油箱容积 (L) | 配置面板 | 油表归零后仍可使用的备用油量 | 5 |
| 平均油耗 (L/100km) | 配置面板 | 车辆百公里平均油耗 | — |
| 剩余续航 (km) | 主输入区 | 仪表盘显示的剩余可行驶里程 | — |
| 汽油单价 (元/升) | 主输入区 | 当前油价 | — |
| 每升优惠价 (元) | 折扣计算面板 | 加油站每升优惠金额 | — |
| 加油机输入金额 (元) | 折扣计算面板 | 加油机上输入的支付金额 | — |

## 计算逻辑

```
续航油量 = (剩余续航 × 平均油耗) / 100
总剩余油量 = 隐藏油箱容积 + 续航油量
可加注油量 = max(0, 油箱总容积 - 总剩余油量)
预计费用 = 可加注油量 × 汽油单价
每公里花费 = 汽油单价 × (平均油耗 / 100)
折扣每公里花费 = (汽油单价 - 每升优惠价) × (平均油耗 / 100)
折扣率 = (每升优惠价 / 汽油单价) × 100
支付百分比 = 100 - 折扣率
加油容积 = 加油机输入金额 / 汽油单价
实际支付金额 = 加油容积 × (汽油单价 - 每升优惠价)
```

## UI 设计

- 基于 Vuetify Material Design 基础样式
- 卡片式布局，最大宽度 600px，适配手机竖屏
- 渐变背景（`#f5f7fa → #e9eef3`）
- 浮动标签（Floating Labels）输入框
- Ripple 波纹按钮效果
- Expansion Panel 可折叠配置区域（配置信息 + 折扣计算两个独立面板）
- 折扣结果 Chip 标签（实际支付金额/加油容积），绿色/蓝色 Material 风格徽章
- Bottom Sheet 移动端原生风格确认弹窗
- 固定顶部结果栏，键盘弹起时自动调整位置，折扣百分比展示在详情行右侧

## 浏览器兼容性

- 依赖 `localStorage` API（数据持久化）
- 依赖 `window.visualViewport` API（移动端键盘适配）
- 推荐使用 Chrome（Android）或 Firefox 移动版

> **注意**：iOS（所有浏览器均基于 WebKit）对 `file://` 协议下的 `localStorage` 支持不完善，详见上方「快速开始」。
